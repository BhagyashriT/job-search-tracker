# Job Search Tracker

A full-stack application for tracking job applications, interviews,
recruiters, follow-ups, and job-search analytics.

## Planned Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- JUnit

### Frontend
- React
- TypeScript
- Vite

### Infrastructure
- Docker
- Docker Compose

### CI
- GitHub Actions

## Planned Features

- Track companies and job applications
- Track interview stages
- Track recruiters and contacts
- Add interview notes
- Track follow-up dates
- Search and filter applications
- Job search analytics dashboard
- CSV import/export
